# Site-Informativo-LibrasParaTodos
Site sobre aspectos das Libras feito sob os requisitos da professora Suzana Lustosa, para a matéria de Desenvolvimento Web

Libras para Todos

*Sobre o projeto*
Este é um site educativo sobre a importância da Libras para a inclusão social e a acessibilidade, especialmente em momentos de crise socioeconômica.

*Tecnologias*
- HTML5: estrutura da página.
- CSS3 e Flexbox: aparência, organização e adaptação a telas menores.
- JavaScript: validação do formulário e exibição de mensagens.
- iframe: incorporação de um vídeo do YouTube.

*Requisitos do projeto*
HTML
- Estrutura semântica com header, nav, main, section, article, aside e footer.
- Imagens, links, tabela, lista e vídeo incorporado.
- Formulário com campos identificados por label, validação e botões de enviar e limpar.
CSS
- Arquivo externo style.css.
- Seletores por tag, classe, ID e universal.
- Cores, fontes, espaçamentos e estilos dos elementos.
- Flexbox para alinhar e distribuir elementos.
- Media queries para telas menores.
JavaScript
- Arquivo externo script.js.
- Captura dos dados do formulário com .value.
- Uso de const e let.
- Verificação dos campos com if, else if, else e operadores lógicos.
- Mensagens personalizadas exibidas com innerHTML.
- Evento reset para limpar a mensagem.

*Funções importantes do JavaScript*
- getElementById(): encontra um elemento pelo seu id.
- addEventListener(): detecta eventos, como o envio do formulário.
- preventDefault(): impede o recarregamento padrão da página ao enviar.
- .value: obtém o valor digitado ou selecionado.
- .trim(): remove espaços no início e no fim do texto.
- if e else: executam ações conforme as condições.
- innerHTML: exibe a mensagem na página.
- return: encerra a função quando a validação falha.

*Como testar*
1. Abra index.html no navegador.
2. Confira se as imagens, os links e o vídeo funcionam.
3. Envie o formulário vazio e observe a validação.
4. Preencha o formulário, teste diferentes níveis de Libras e confira a mensagem.
5. Clique em Limpar formulário.

*Observação*
O formulário exibe resultados na página, mas não envia nem salva os dados em um servidor ou banco de dados.
